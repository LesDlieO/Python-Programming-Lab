## 如何运行

1. 安装 Python 3.10 或更高版本（[python.org](https://www.python.org/downloads/)）。
2. 克隆本仓库：

   ```bash
   git clone <你的仓库地址>
   cd Python-Programming-Lab
   ```

3. 进入对应周次文件夹，运行：

   ```bash
   python main.py
   ```

## 提交规范（Commit 约定）

| 前缀 | 含义 |
| :--- | :--- |
| `feat:` | 新增实验代码或功能 |
| `fix:` | 修复代码问题 |
| `docs:` | 更新文档 / 实验报告 |
| `refactor:` | 重构代码（不改变功能） |
| `chore:` | 杂项（配置、目录调整等） |

示例：`feat(第05周): 完成循环结构实验代码`
