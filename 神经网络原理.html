神经网络原理
神经元 网络结构 前向传播 激活函数 反向传播 训练演示

神经网络，
一台会自己写规则的机器

传统程序需要人类把规则一条条写清楚；神经网络则相反——你只给它输入和答案， 它自己从数据里“学”出规则。下面我们用动画一步步拆解它的原理。

一句话概括

神经网络 = 一堆 神经元 分层连接， 数据向前流动得到预测（前向传播）， 把误差沿反方向传回去修正连接强度（反向传播）， 反复循环直到预测足够准。

01神经元：最小的计算单元

神经元是神经网络的积木。它接收多个输入，加权求和，再通过一个非线性函数输出。

生物到数学的类比

生物神经元有树突接收信号、胞体处理信号、轴突输出信号。人工神经元照搬了这个结构：

  • 输入 x₁, x₂, x₃ … 相当于树突接收的信号。
  • 每个输入乘上一个权重 w，表示这条连接的重要性。
  • 全部加起来，再加一个偏置 b，相当于“触发的门槛”。
  • 结果经过激活函数，得到输出。

计算过程（动画）

输出 y = f( w₁·x₁ + w₂·x₂ + w₃·x₃ + b ) = f( Σ wᵢxᵢ + b )

02网络结构：分层协作

把神经元排成层：输入层 → 隐藏层 → 输出层。数据从左往右流动。

输入层隐藏层输出层 —— 隐藏层可以有 很多层（这就是“深度”学习的由来）。

每一层在做什么

输入层：把原始数据（如一张图片的每个像素）转成数字。

隐藏层：逐层抽取越来越抽象的特征。比如识别猫时，第一层看边缘、第二层看形状、第三层看“猫脸”的组合。

输出层：给出最终答案，如“猫 / 狗”的概率。

为什么需要“深”

单层网络能解决的模式很有限。叠加多层后，网络可以把简单特征组合成复杂概念——这正是它强大的原因。

直觉：一层做“加减”，多层能做“整个数学”。

03前向传播：数据从左到右

用数字走一遍

隐藏层 h₁ = f( 0.8×1 + 0.5×0.2 ) = f( 0.90 ) = 0.71 输出 ŷ = f( h₁·w + b ) → 与真实答案比较 → 得到误差

前向传播只是“按现在的参数算一遍”。如果预测错了怎么办？下一步，反向传播出场。

04激活函数：给网络加“曲线”

如果没有激活函数，无论多少层，整个网络都只是线性变换，能力有限。激活函数引入非线性。

05反向传播：让错误“倒流”回去修正

核心思想：算出每个权重对最终误差的“贡献”，然后往能减少误差的方向微调它。

四步循环

  • 前向传播：算出预测 ŷ。
  • 算损失：用损失函数衡量 ŷ 和真实值 y 差多远。
  • 反向传播：用链式法则（微积分）把误差逐层回传，求出每个权重的梯度。
  • 更新参数：沿梯度反方向移动一小步（学习率 η）。

梯度下降

想象在山谷里蒙眼下山：每一步都朝“脚下最陡的下坡方向”迈一小步。梯度就是那个“最陡方向”。

w ← w − η · ∂L/∂w

η 是学习率：太小→学得慢；太大→可能跨过头、来回震荡。

为什么叫“反向”？ 前向传播从左到右，反向传播则从输出层的误差开始，从右到左、一层层把误差的“责任”分摊给每个权重——所以是“反向”。
